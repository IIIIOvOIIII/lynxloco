## 延长窗口的实际作用与代价

**15 个成功窗口的整体处理耗时超过 120 秒，其中 2 次模型请求的 HTTP 阶段也超过 120 秒。** 这说明新的时限容纳了部分原 120 秒窗口无法容纳的慢处理。

代价是允许更晚的结果完成。成功窗口整体处理 P95 为 **134.1 秒**，比上轮 115.4 秒更长；延长超时改善的是完成机会，并没有把每次识别变成即时响应。两档成功样本的组成也随取消边界改变，不能将 P95 差异单独解释为模型本身速度变化。

唯一失败为 `CancelledError`，网关对应 `request_canceled/499`：输入等待约 5.1 秒，处理约 174.9 秒，合计接近 180 秒窗口预算；其中等待请求名额约 9.0 秒、HTTP 阶段约 165.8 秒。180 秒仍不能消除所有极慢请求。
