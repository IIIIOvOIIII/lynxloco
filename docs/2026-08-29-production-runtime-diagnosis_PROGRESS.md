- Result detail: Read-only source tracing explains the observed slope. Every RTSP decoded video frame is converted to a full-resolution BGR ndarray and inserted into the perception synchronization buffer at the camera's source frame rate. The default buffer uses four-second windows and retains up to three drained windows plus the active window; downsampling to the configured 3 fps occurs only later at pipeline entry. With two high-rate 1280x720 streams, buffered BGR frames alone can occupy roughly 2.1-2.5 GiB before PyAV/FFmpeg, ONNX Runtime, Python objects, and conditional browser-transcode copies. Existing queue-count limits therefore remain logically bounded but do not impose a safe byte budget.
